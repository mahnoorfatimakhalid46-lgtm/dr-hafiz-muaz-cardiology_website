# Dr. Hafiz Muhammad Muaz - Cardiology Clinic Website

### ✨ Features
- **Premium Dark UI** - Manrope font, red/black theme, glassmorphism
- **Fully Responsive** - Mobile, Tablet, Desktop optimized
- **Appointment Booking** - Direct WhatsApp integration
- **AI Chatbot** - Instant replies for timing, location, chest pain emergency, fee
- **Animated ECG & Heartbeat** - CSS keyframe animations
- **Reveal on Scroll** - IntersectionObserver animations
- **Emergency Floating Buttons** - Call, WhatsApp, Chat, Top scroll

### 🛠️ Tech Stack
- HTML5
- CSS3 (Custom Variables, Grid, Flexbox, Animations)
- Vanilla JavaScript
- Font Awesome 6
- Google Fonts (Manrope)
